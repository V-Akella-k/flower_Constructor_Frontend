# 3D Flower Constructor - Frontend

**Описание проекта**
Веб-приложения для создания 3D композиций из цветов, ваз и корзин.

## Технологии

- React + TypeScript
- MobX
- React Router DOM
- Three.js + @react-three/fiber
- Vite

## Быстрый старт

```console
git clone https://github.com/Sponk1/flower-constructor-frontend.git
cd flower-constructor-frontend
npm install
npm run dev
```

## Стандарт кода

- [Архитектура FSD](https://feature-sliced.github.io/documentation/ru)
- Абсолютные импорты через `@/...`
- Для каждой отдельной задачи создается ветка формата:
  
  `fix/...`
  
  `feat(или feature)/...`
  
  `refactor/...`
  
  `hotfix/...`
- Коммиты создаются вида:
  
  `fix: ...`
  
  `feat: ...`
  
  `refactor: ...`
